# Samples

Recordings from [VSCO 2 Community Edition](https://versilian-studios.com/vsco-community/)
by Versilian Studios, which is public domain (CC0). The originals are at
https://github.com/sgossner/VSCO-2-CE.

`tools/prepare_samples.py` made these from them: mono, 32 kHz, 16-bit,
trimmed, faded and normalized, named by the pitch they actually sound
(VSCO names some instruments an octave low). `samples.json` lists each
recording's measured pitch in Hz, or null for unpitched ones.
